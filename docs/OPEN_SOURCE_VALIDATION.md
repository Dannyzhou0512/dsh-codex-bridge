# 开源前验证

## Windows 公开预览包

主插件 0.0.10 和 UI 0.0.9 适配 DSH 0.2.2-rc.3。最终包在隔离 Web profile 完成扫描、从预览发起单条导入、重复识别、无效目录重映射和仅试跑。窄窗口可操作确认面板，批量复选框只在批量模式显示。验收来源均为合成历史。

从干净源码安装开发依赖后，主插件 167 项测试、UI 13 项测试、类型检查和主包实际解包验证均通过。两份安装包和工作区产物的 SHA-256 一致。

使用独立 Windows Electron 数据目录初始化并安装 Desktop profile。验证预览入口导入、原生会话中显示历史回复、冷启动读回及重复导入识别。自动关闭窗口超时，本次在确认读回后结束隔离进程进行冷启动，正常退出未在本轮自动化中验证。

## DSH 0.2.2-rc.3 适配验收

主插件 0.0.10 和可选 UI 0.0.4 preview。主插件 167 项、UI 12 项，以及主包实际解包验证通过。Codex CLI 0.169.0-alpha.11.1 的 10 份公开协议 schema 校验通过，并用本机 App Server 只读复核了一条完整历史。

本机 Windows DSH 0.2.2-rc.3 在隔离 profile 通过主包安装、扫描、预览、Dry-run、合成单条导入、Workspace 关联和原生合成续聊。升级夹具中的 0.0.9 旧导入记录通过新版分页读取器被识别为 `already-imported`。实际 Web 侧栏完成安装、扫描、预览、Dry-run、合成导入和重复审核，冷重启后仍识别为已导入。

正式 Desktop 部署、Electron 窗口验收和新版真实模型续聊留待单独验证。使用步骤见[当前使用指南](USAGE.md)。
