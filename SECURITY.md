# Security

This preview plugin imports public history into a trusted local Harness profile. It is not a multi-tenant authorization boundary. Review handles are bearer capabilities inside the same authenticated Host; protect that Host and do not expose its credentials.

Do not post secrets or real chat content in public issues. For non-sensitive bugs use a synthetic reproduction with package/Harness/Codex versions and finite error codes. For sensitive reports contact the repository owner without attachments containing secrets.

Known limitations are in docs/LIMITATIONS.md: entire Client factory failure can block Core frontend startup in rc.2, renderer crash cause is unresolved, and partial writes may remain after interruption. No blanket startup-safety or zero-data-loss guarantee is made.
